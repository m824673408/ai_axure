# 归因联调设备白名单原型

一个 Vue 3 + Element Plus 前端原型，用于演示归因联调设备的白名单登记、筛选、数据清空确认和状态反馈。

## 启动

双击 [双击打开原型.vbs](./双击打开原型.vbs) 即可后台启动服务并打开浏览器。首次启动会自动安装依赖。

如果需要查看启动过程或排查失败原因，再双击 `启动原型.cmd`，它会保留可读的英文系统错误提示。

也可以手动启动：

```powershell
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址即可。双击入口会自动选择可用的本地端口；手动启动默认使用 `4315`。

部署到 Ubuntu 内网服务器的方式见 [DEPLOYMENT.md](./DEPLOYMENT.md)。

## 原型边界

- 所有设备列表和清空结果仅保存在浏览器内存中，刷新页面会恢复演示数据。
- “清空数据”会展示明确的二次确认，并模拟设备状态变化，不会调用后端或删除真实数据。
- 如需接入真实联调环境，建议后续由后端提供受审计的清空接口，并保留操作人、时间和请求结果。
