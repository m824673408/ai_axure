# Product Diff

## 页面

- **归因结果（attribution_result，`prototype/src/pages/AttributionResultsPage.tsx`）**
  - 页面描述文案由「按设备和事件查看归因命中结果。」调整为「按设备、媒体、事件和状态查看归因命中结果。」
  - 查询区域由 2 个控件扩展为 5 个控件：设备标识、媒体、事件类型、归因状态、事件时间范围。
  - 结果摘要由「最近结果」改为「当前结果 N 条」，条数随筛选结果联动。
  - 表格新增空态文案「没有符合当前条件的归因结果」。
  - 演示数据由 2 条扩展为 4 条，新增「磁力引擎 / 待生效」「巨量引擎 / 已归档」两条记录，页面初始展示条数由 2 条变为 4 条。
  - 变更范围内无新增页面、无导航与路由变化。

## 交互

- **查询结果**：按钮由静态按钮改为提交动作，点击后将当前草稿条件应用为生效条件，表格与摘要条数同步刷新。
- **重置条件**：查询区域新增「重置条件」次级按钮，点击后同时清空草稿条件与已生效条件，恢复完整列表。
- **条件编辑与生效分离**：设备标识、媒体、事件类型、状态均只写入草稿态，未点击「查询结果」前不改变表格结果。
- **媒体选择**：复用既有 MediaSelector，返回媒体编码作为筛选值。
- **事件类型 / 状态选择**：新增两个 Select，均支持清除（allowClear），占位文案分别为「全部事件」「全部状态」。
- **时间范围**：沿用既有 RangePicker，本次未绑定取值与变更处理，不参与筛选。
- **设备标识**：输入即时更新草稿，提交后以不区分大小写的子串匹配过滤。

## 产品规则

- 多个已填写条件按 AND 关系组合，仅展示同时满足全部条件的记录。
- 未填写的条件（未选媒体 / 未选事件 / 未选状态 / 设备标识为空）不参与筛选。
- 重置后清空全部条件并恢复完整结果列表。
- 状态枚举映射为：`active` → 已启用、`pending` → 待生效、`archived` → 已归档。
- 事件类型选项固定为「应用激活」「首次付费」。
- 数据来源仍为页面内静态演示数据，不接入真实查询接口。
- 未涉及导航、路由、全局 Layout、主题与共享组件规则的修改。

## 风险

- **时间范围筛选未落地**：RangePicker 仍为无绑定控件，用户可选择时间但结果不受影响，与「按条件组合筛选」的页面预期存在不一致，可能造成误导。需求正文未将时间范围列入新增筛选，需确认是否为本次有意排除。
- **设备标识匹配语义未定义**：实现采用不区分大小写的子串匹配，需求仅描述「输入可选设备标识」，未定义精确匹配还是模糊匹配，产品行为需确认。
- **事件类型选项硬编码**：选项固定为两项，若演示数据或后续数据新增事件类型，该筛选项将无法覆盖，存在筛选遗漏风险。
- **媒体筛选依赖编码约定**：筛选通过记录 `mediaCode` 与 MediaSelector 取值比对，二者取值口径需保持一致，否则媒体筛选会静默失效。
- **演示数据变化影响初始视图**：初始结果条数由 2 条变为 4 条，会改变未做任何操作时的页面呈现，需确认演示预期。
- **状态枚举与展示映射需对齐**：表格 StatusTag 与筛选下拉的状态取值集合必须保持同步，后续若新增状态值，两处均需更新。
- **筛选后无结果的表现**：已提供空态文案，但摘要仍显示「当前结果 0 条」，该组合呈现是否符合预期待确认。
