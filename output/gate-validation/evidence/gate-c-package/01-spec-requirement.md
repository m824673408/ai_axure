# 联调白名单

## 背景

联调设备需要临时绕过部分测试环境限制，目前缺少统一入口维护设备类型、有效期和启用状态。

## 目标

在归因管理下新增“联调白名单”页面，支持查询现有设备并添加具有明确有效期的联调设备。

## 用户行为

用户从左侧“归因管理”进入“联调白名单”；可以按设备标识、设备类型和状态查询。点击“添加设备”打开侧边表单，填写设备类型、完整设备标识和有效天数后提交，新设备立即出现在列表顶部。

## 页面变化

- 归因管理导航新增“联调白名单”。
- 新增 `/attribution/device-whitelist` 路由和对应页面。
- 页面复用 PageLayout、SearchForm、DataTable 和 StatusTag，不创建第二套 Layout。

## 核心规则

- 设备标识和设备类型必填，有效天数为 1 至 90 天。
- 列表中的设备标识必须脱敏展示。
- 新增设备默认状态为已启用，创建人为“当前用户”。
- 查询条件按 AND 关系组合，重置恢复完整列表。
- 本 Feature 不修改全局主题和共享组件。

## 补充说明

使用前端静态数据演示，不接入真实白名单接口；删除、批量导入和审批不在本次范围内。
